As discussed, I am sending you an English-language package describing the Agent plans and instruction architecture used in the Research Integrity Systems in Europe / LERU Integrity Map project.

The package contains two main documents:

- an inventory of the different forms of planning and instruction used in the project; and
- a practical guide to designing effective Agent plans, including reusable templates, quality gates, stop conditions, definitions of done, handoff requirements, and common failure modes.

I have also included the underlying working examples: the standing project handoff, phase and feature plans, repeatable workflows, status and gap documents, record-level next actions, country working notes, and examples of the source and extraction audit trail.

The main design principle is that one document should not try to do everything. The project separates:

1. standing instructions that define what must always remain true;
2. phase or product plans that define the intended outcome;
3. workflows that define how a repeatable task is performed;
4. status documents that record progress and the next task; and
5. microplans that identify the next concrete action for each country or institution.

I suggest starting with `00_START-HERE.md`, followed by the English inventory and the Agent Plan Design Guide in the `01_overview` folder.

The materials describe a project method and working architecture. They should not be read as an official LERU policy statement or as an institutional audit.
